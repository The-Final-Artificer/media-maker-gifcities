### GifCities graphics (auto-download)

Any field that takes a file path (the `src` of `gif`, `image`, `divider` and `download` rows, a `list` row's bullet `src`, `img:` badge lines, a site's `bgimage`, a newspaper's main image) also accepts `gifcities:term` or `gifcities:term:N`. On import the module searches the Internet Archive's GifCities collection (real GeoCities-era gifs) for that term, downloads the gif into the GM's own library and substitutes the local path. The CSV itself never contains the image.

- `gifcities:flame` takes the first search result for "flame". If the GM ticks the import window's Variety option, every unnumbered token picks a random result instead; gifs already in the library are reused, new picks download.
- `gifcities:flame:7` takes the 7th result; numbers past the end wrap around. Use different numbers to get different gifs for the same term.
- A numbered token always gives the same gif, with or without Variety, so use numbers when a graphic must stay identical across imports.
- A term with no results is skipped with a warning and the slot stays empty, so prefer terms from the indexed list below. Searching matches substrings, so `skulls` still finds `skull`.
